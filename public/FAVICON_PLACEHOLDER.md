# Favicon and Image Requirements

Please create and add the following image files to the `/public` directory:

## Required Favicon Files

1. **favicon-16x16.png**
   - Size: 16x16 pixels
   - Format: PNG
   - Purpose: Browser tab icon (small)

2. **favicon-32x32.png**
   - Size: 32x32 pixels
   - Format: PNG
   - Purpose: Browser tab icon (standard)

3. **apple-touch-icon.png**
   - Size: 180x180 pixels
   - Format: PNG
   - Purpose: iOS home screen icon

## Social Media Image Files

4. **og-image.jpg**
   - Size: 1200x630 pixels
   - Format: JPG
   - Purpose: Facebook/LinkedIn preview image
   - Recommended: Photo of El Paso skyline or Lorena with sold sign

5. **twitter-image.jpg**
   - Size: 1200x675 pixels
   - Format: JPG
   - Purpose: Twitter card preview image
   - Recommended: Same as og-image or branded alternative

## Design Guidelines

- Use brand colors: Gold (#C9A84C) and Dark (#0A0A0A)
- Include "Casas En El Paso TX" branding
- Keep designs clean and professional
- Ensure good contrast for small sizes (favicons)
